## Что должно заработать

Четыре оставшиеся сцены сценария.

**Skin Layers** — разрез кожи в пастельной палитре расслаивается по прокрутке:
эпидермис, дерма, подкожный слой, фолликул; луч лазера доходит до корня. Это
объяснение «как работает», нарисованное вектором, без фотографий.

**Cards** — две подсцены: «как это проходит» шагами и «почему лазер» карточками,
появляются каскадом. Плюс цены таблицей по зонам из конфига (скрыты, если зон нет).

**Counter** — цифры студии набегают, когда доходят до экрана, ровно один раз.

**CTA** — финальный экран: кнопка записи ведёт на сервис из конфига, рядом
телефон и мессенджеры. Если ссылка сервиса не вписана — кнопка ведёт на телефон;
если и телефона нет — кнопка неактивна и честно подписана.

## Критерии приёмки

- [ ] Skin Layers: цвета слоёв по §14 (эпидермис `--peach`, дерма `--rose`, подкожный `--sand`, фолликул и луч `--lilac`, подписи `--ink`); слои расходятся по прокрутке, луч доходит до фолликула
- [ ] How It Works: ≥4 нумерованных шага, каскадное появление
- [ ] Benefits: ≥4 карточки, сравнение с воском читается
- [ ] Цены: таблица по зонам из `studio.prices`; пустой массив — блок скрыт целиком
- [ ] Stats: ≥3 счётчика, значения из `studio.stats`, анимация один раз (`once: true`), при прокрутке туда-сюда не перезапускается
- [ ] Незаполненный счётчик показывает заглушку, а не выдуманное число
- [ ] CTA: кнопка → `studio.bookingUrl`; если заглушка → `tel:`; если и телефон заглушка → кнопка `disabled` с подписью, почему
- [ ] Телефон и мессенджеры рядом с кнопкой; незаполненные скрыты
- [ ] Все четыре сцены закрепляются через реестр таска 02; ни одного собственного ScrollTrigger
- [ ] При `prefers-reduced-motion` все секции читаемы без движения, счётчики показывают конечные значения
