## Что должно заработать

Прокрутка становится плавной (Lenis), и появляется механизм, которым дальше
собираются все 13 сцен: секция регистрирует свою сцену по id, получает таймлайн,
привязанный к скроллу, и больше ни о чём не думает — pin, скраб, обратный ход,
пересчёт на resize и уборка при размонтировании делаются в одном месте.

Между сценами работает вспышка: короткий засвет и мягкое свечение, которое
перекрывает стык. Поверх страницы плавают размытые лепестки и еле видны
тонкие дуги — они сквозные для всего сайта, не принадлежат hero.

Если у посетителя включено «уменьшить анимацию» — ничего не двигается,
не вспыхивает и не закрепляется, а весь контент на месте.

## Критерии приёмки

- [ ] `lib/motion/scene-ids.ts` содержит все 13 id из §4 и только их — секции берут id оттуда
- [ ] `useScene(id, build)` регистрирует таймлайн; создание, `refresh()` на resize с debounce и полная уборка ScrollTrigger'ов живут в `MotionProvider`, не в секциях
- [ ] Lenis подключён к тикеру GSAP — один rAF-цикл на весь сайт, второго нет
- [ ] Lenis не ломает Tab-навигацию и якорные ссылки
- [ ] Все таймлайны скраббятся в обе стороны: прокрутка назад проигрывает сцену обратно
- [ ] Обновление страницы посреди сцены восстанавливает нужный кадр (учтён `scrollRestoration`, `ScrollTrigger.refresh()` после восстановления)
- [ ] Поворот экрана и resize не разъезжают сцены; высоты pin в `vh`
- [ ] `<FlashTransition>`: длительность 160 мс, не чаще одной вспышки за 600 мс, перепад относительной яркости < 0.1 — значение проверено тестом, не на глаз
- [ ] `<Petals>`: ≥7 лепестков, ≥3 степени размытия, часть выходит за край карточки; размытие предрендеренными спрайтами, а не `filter: blur()` в анимации
- [ ] `<Arcs>`: ≥3 дуги толщиной ≤1 px, цвет из палитры с alpha, медленный дрейф по скроллу
- [ ] `will-change` ставится перед сценой и снимается после — не висит постоянно
- [ ] В анимациях только `transform`, `opacity`, `filter`
- [ ] При `prefers-reduced-motion: reduce`: нет pin, нет вспышек, нет дрейфа декора, таймлайны отданы в конечном состоянии, контент целиком доступен
- [ ] Анимируемые элементы имеют стартовое состояние из CSS — нет вспышки неоформленной страницы до инициализации GSAP
- [ ] Framer Motion не участвует в прокруточной анимации ни в одном месте
